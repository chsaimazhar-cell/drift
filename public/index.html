FAQ

Good questions
deserve clear answers.

What kind of links can I use?+

Drift is designed for publicly accessible media from supported platforms. Private content, DRM, authentication bypasses and other access-control circumvention are not supported.

Do I need an account?+

No. The initial project keeps the core experience account-free. Local preferences and recent items can be stored in your browser.

Will every video have 1080p?+

No. Available quality depends on the public media source. The interface only presents formats that the backend can legitimately retrieve.

Can I add more platforms later?+

Yes. The Python backend is organized around platform adapters so new supported sources can be added without rewriting the frontend.
